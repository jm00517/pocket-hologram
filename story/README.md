# 스토리 쓰는 법

미연시 레이어는 [Ink](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md)(inkle) 스크립트로 움직인다.
`story/main.ink`가 입구이고, `INCLUDE`로 파일을 나눌 수 있다. 맨 위에는 항상 `INCLUDE lib.ink`를 둔다.
Ink 문법(노트, 선택지, 변수, 조건, 함수)은 그대로 쓰고, 이 게임은 그 위에 **대사 줄 형식**, **연출 태그**, **트리거**, **외부 함수**를 얹는다.
게임은 런타임에 inkjs 2.3.2로 컴파일한다(빌드 없음). Inky로 써도 되고, 게임 안의 개발자 도구(`tools/dev.html`)로 써도 된다.

```ink
INCLUDE lib.ink
# speaker: ミク = miku
# player: 나
VAR affection = 0
-> intro

=== intro ===
ミク: あ、きたきた！ #ko:아, 왔다 왔다! #expr:happy #motion:wave
ミク: きょうは なにする？ #ko:오늘은 뭐 할래?
* [같이 산책하자 #nod]
    ~ affection += 1
    ミク: やった！ #ko:신난다! #fx:heart
* [조금 쉬고 싶어 #shake]
    ミク: そっか、じゃあ ここで ゆっくりしよ #ko:그렇구나, 그럼 여기서 쉬자 #expr:smile
- -> DONE
```

## 대사 줄

`이름: 대사 #ko:번역 #연출...`

| 줄 | 화면 | 목소리 |
|---|---|---|
| `ミク: こんにちは` | 이름표 + 대사 | 화자의 목소리 (`# speaker:`) |
| `나: 안녕` (`# player:` 에 있는 이름) | 내 대사 (다른 색) | 없음 |
| 이름 없는 줄 | 나레이션 (기울임) | 없음 |

- 이름은 `# speaker:` 또는 `# player:`에 선언된 것만 화자로 인식한다. 선언하지 않은 `시각: 3시`는 나레이션으로 그대로 나온다.
  `:`와 `：`(전각) 둘 다 쓸 수 있다.
- 기본 화자: `ミク`, `미쿠`, `Miku` → `miku` 목소리. 기본 플레이어: `나`.
- 미쿠 목소리(VOCALOID6)는 **일본어만** 부른다. 대사는 일본어로 쓰고, 번역은 `#ko:`로 붙인다. 한자는 읽어 주지만
  틀리게 읽으면 `#yomi:ひらがな`로 읽기를 고친다(화면에는 원문이 나온다).
- 자막 언어는 설정 `story.subs`(기본 `ko`)로 고른다. 2글자 언어 코드 태그(`#ko:` `#en:` `#ja:`)가 자막이다.
- 선택지를 고른 직후 Ink가 선택지 글을 그대로 한 줄로 내보내면(대괄호 `[...]` 없이 쓴 선택지) 내 대사로 표시된다.

## 연출 태그

한 줄의 태그는 **그 줄이 시작할 때** 순서대로 실행된다. `wait` `fade` `map` `walk` `input` `cmd`는 끝날 때까지 기다리고(줄이 그 뒤에 나온다), 나머지는 바로 넘어간다.
대사 없이 태그만 있는 줄도 된다(예: 노트 끝의 `#bgm:stop`).

| 태그 | 하는 일 |
|---|---|
| `#expr:<표정> [hold] [len=<초>]` | 표정. `neutral` `smile` `happy` `surprised` `shy` `sad` `angry` `pout` `wink` `heart` `sparkle`. `hold`면 다음 표정까지 유지 |
| `#motion:<이름>` | 모션 클립(`bow` `hi` `wave` `wave2` `raise` `cheer` `clap` `shy` `shybow` `guide` …, 개발자 도구에 목록이 있음) |
| `#react:<이름>` | 짧은 몸 반응: `nod` `shake` `tilt` `bounce` `recoil` `lookdown` `wave` |
| `#state:<상태>` | 대화 자세: `idle` `listening` `thinking` `speaking` |
| `#hands:<모드>` | 손 모양 (`auto` 등, 개발자 도구에 목록이 있음) |
| `#look:<어디>` | 시선: `you` `away` `down` `up` `left` `right`(그녀 기준 왼쪽/오른쪽), `free` = 원래대로 (장면이 끝나면 풀림) |
| `#walk:<x> <z>` | 그 자리(무대 미터, 그녀가 처음 선 곳이 0,0)로 걸어간다 |
| `#place:<x> <z> [yaw도]` | 그 자리로 바로 옮긴다 |
| `#face:you` / `#face:<yaw도>` | 나를 보거나 그 방향으로 돈다 |
| `#follow:on` / `#follow:off` | VR에서 나를 따라오기 (장면 중에는 기본 off) |
| `#map:<맵 id>` | 맵 이동 (`grid` = 맵 없음) |
| `#time:<morning\|day\|evening\|night>` | 맵의 해 위치를 그 시간대로 (실제 시각 연동은 꺼짐) |
| `#bgm:<이름> [fade=<초>] [vol=<0-1>]` / `#bgm:stop` | 배경음악 `assets/music/<이름>.ogg\|mp3` (없으면 조용히 넘어감) |
| `#sfx:<이름> [vol=<0-1>]` | 효과음 `assets/sfx/<이름>.ogg\|wav\|mp3`. 내장: `pop` `chime` |
| `#fx:<이모트>` | 머리 위 만화 기호: `heart` `sparkle` `sweat` `anger` `question` `exclaim` `note` `zzz` |
| `#wait:<초>` | 기다린다 |
| `#fade:out [초]` / `#fade:in [초]` | 화면 암전 / 밝아짐 (VR에서도) |
| `#clear` | 대사 상자를 잠깐 숨긴다 (다음 대사에서 다시 나옴) |
| `#auto:<초>` | 이 줄은 클릭 없이 그 시간 뒤 넘어간다 |
| `#timer:<초>` | (선택지 바로 앞 줄) 선택지에 제한 시간. 시간이 다 되면 `#default` 선택지(없으면 마지막)가 골라진다 |
| `#style:whisper` | 이 줄은 속삭이듯 |
| `#voice:off` | 이 줄은 목소리 없이 글자만 |
| `#yomi:<가나>` | 목소리가 읽을 글 (화면 글과 따로) |
| `#memory:<id> <제목>` | 추억 갤러리에 등록 (그 순간의 스크린샷과 함께). 메뉴에서 다시 보면 그 노트를 처음부터 끝까지 재생하고, 끝나면 원래 상태로 돌아온다 (그래서 `-> DONE`으로 끝나는 노트에 둔다) |
| `#input:<변수> <질문>` | 플레이어에게 글을 받아 Ink 변수에 넣는다 (VR에서는 말로 대답) |
| `#set:<param>=<값>` | 엔진 파라미터 아무거나 (`#set:post.bloom=0.6`) |
| `#cmd:<명령> <키>=<값>…` | 엔진 명령 아무거나 (`#cmd:crossing.moveTo x=2 z=-3`). Ink는 태그 안의 `{ }`를 로직으로 읽어서 JSON은 못 쓴다 |

## 선택지

Ink 선택지(`*`, `+`, `[...]`) 그대로. 선택지 태그는 **대괄호 안에** 쓴다(`* [손 잡을래 #on:touch.hand]`). `]` 뒤에 쓰면 Ink가 선택한 뒤의 줄에 붙여 버린다(검사가 알려 준다). 대괄호 없는 선택지는 줄 끝에 써도 된다.

| 태그 | 뜻 |
|---|---|
| `#nod` / `#shake` | VR에서 고개를 끄덕이면 / 저으면 이 선택지 |
| `#on:<이벤트>` | 그 이벤트가 일어나면 이 선택지 (`#on:touch.hand` = 손을 잡으면, `#on:touch.headpat` = 머리를 쓰다듬으면) |
| `#default` | `#timer`가 다 됐을 때 골라지는 선택지 |

고르는 방법: 클릭/숫자키(데스크톱), 레이저+트리거/손가락으로 누르기(VR), 말로 대답하기(마이크/트리거를 누른 채 선택지 글을 말함), 그리고 위 태그의 몸짓.
말로 대답할 때는 띄어쓰기·문장부호는 무시되고, 선택지 글이 통째로(또는 두 글자 이상 한 조각이) 들어 있으면 그것, 아니면 가장 비슷한 선택지가
골라진다(음성 인식이 조금 틀려도 된다). 아무것도 안 비슷하면 다시 기다린다. 데스크톱에서는 선택지나 `#input` 질문이 떠 있는 동안 화면 아래
채팅 칸이 다시 나온다: 거기에 쓰거나 🎤를 누른 채 말하면 대답이 된다(그녀와의 자유 대화로 가지 않는다).

## 트리거: 그녀가 반응하는 순간

노트 맨 위의 태그가 그 노트를 이벤트에 묶는다. 장면이 진행 중이 아닐 때(자유 모드) 이벤트가 오면 맞는 노트가 장면으로 재생된다.

```ink
=== pat_reaction ===
# on: touch.headpat
# cooldown: 120
# when: likes_me
ミク: えへへ、もっと #ko:헤헤… 더 해줘 #expr:happy
~ affection += 1
-> DONE

=== function likes_me() ===
~ return affection >= 3
```

| 태그 | 뜻 |
|---|---|
| `# on: <이벤트>, <이벤트>…` | 이 이벤트들에 반응. `map.*`처럼 `.*`로 끝나면 앞부분이 같은 모든 이벤트 |
| `# once` | 세이브마다 한 번만 |
| `# cooldown: <초>` | 한 번 재생한 뒤 이만큼 쉼 |
| `# chance: <0-1>` | 이 확률로만 |
| `# priority: <숫자>` | 여러 노트가 맞으면 높은 것부터 (같으면 위에 쓴 것) |
| `# when: <함수>` | 이 Ink 함수가 true일 때만 |

노트가 재생되기 직전에 `event`(이벤트 이름)와 `event_value`(값)가 써진다(`lib.ink`에 선언됨).

| 이벤트 | 언제 | event_value |
|---|---|---|
| `start` | 처음 시작(새 게임) — 트리거가 없으면 Ink 맨 위 흐름이 재생된다 | |
| `return` | 다시 찾아와서 그녀가 처음 반길 때 | 지난 방문에서 지난 시간(시) |
| `back` | 같은 방문 중 자리를 비웠다 돌아왔을 때 (웹캠/헤드셋) | |
| `map.<id>` | 맵이 바뀌었을 때 (`map.pool`, `map.*`) | |
| `touch.headpat` `touch.poke` `touch.wave` `touch.highfive` `touch.hand` | VR에서 쓰다듬기 / 볼 찌르기 / 손 흔들기 / 하이파이브 / 손잡기 | poke: 그녀의 왼뺨 -1, 오른뺨 1 |
| `near` | 얼굴 바로 앞까지 다가갔을 때 | |
| `gaze` | VR에서 눈을 맞추고 `story.gaze`초 동안 있었을 때 | 초 |
| `head.nod` `head.shake` | VR에서 고개를 끄덕였을 때 / 저었을 때 | |
| `chat` | 자유 대화(LLM)에서 한 번 주고받을 때마다 | 그녀가 느낀 기분 -2..2 |
| `idle` | `story.idle`초 동안 아무 일도 없을 때 | 초 |
| `vr.enter` `vr.exit` | VR 들어감 / 나옴 | |
| `time.morning` `time.day` `time.evening` `time.night` | 시간대가 바뀌었을 때 (실제 시계) | |

트리거 노트는 장면이 진행 중일 때는 무시된다(선택지의 `#on:`은 그때 동작한다). 쓰다듬기 등 VR 터치는 트리거가 받으면 그녀의 기본 혼잣말이 빠지고, 표정과 몸 반응은 그대로 나온다.

## 자유 대화와 성격

장면이 없을 때는 마이크나 채팅으로 그녀와 자유롭게 이야기한다(로컬 LLM). 스토리에 `persona` 함수가 있으면
그 출력이 그녀의 성격 설명에 덧붙는다. 관계가 깊어지면 말투가 바뀌는 식으로 쓴다.

```ink
=== function persona() ===
{ affection >= 10:
    ユーザーとは恋人同士。甘えた口調で話す。
- else:
    ユーザーとは知り合ったばかり。丁寧に話す。
}
```

대화가 한 번 오갈 때마다 `chat` 이벤트가 그녀가 느낀 기분(-2..2)을 싣고 온다:

```ink
=== on_chat ===
# on: chat
~ affection += event_value
-> DONE
```

## 외부 함수 (`lib.ink`)

`hour()` `minute()` `weekday()` `date()` `period()` `map()` `vr()` `near()` `away()` `visits()` `has_motion(이름)` `memory(id)`.
설명은 `lib.ink`에 있다. 함수 인자 이름(`motion_name`, `memory_id`)과 같은 이름의 `VAR`는 만들 수 없다. Ink 내장 `RANDOM(a, b)`, `READ_COUNT(-> 노트)`, `TURNS_SINCE(-> 노트)`도 그대로 쓴다.

## 세이브

자유 모드로 돌아올 때마다, 그리고 페이지를 닫을 때 자동 저장(`auto`)된다. 다시 열면 자동 저장에서 이어서 `return` 이벤트가 온다.
수동 슬롯은 메뉴에서: Esc, 오른쪽 위 📖 버튼, 또는 ☰ 드로어의 `스토리` 칸(메뉴 / 새로 시작 / 개발자 도구). 메뉴의 설정 탭에 글자 속도, 자동 진행,
자막 언어, 대사 목소리 같은 `story.*` 설정이 있고, 바꾼 값은 다음에도 남는다. 세이브는 서버의 `saves/`(git에서 빠짐)에, 서버가 없으면 브라우저 저장소에 들어간다.
읽은 대사(스킵용)와 추억 갤러리는 세이브와 상관없이 남는다.

## 개발자 도구

`tools/dev.html`(서버를 켜고 `http://localhost:3210/tools/dev.html`): 편집기, 컴파일 오류, 검사(lint), 무작위 플레이(퍼즈) 커버리지, 목소리 미리 굽기,
노트 그래프, 그리고 실행 중인 게임을 실시간으로 만지는 패널(변수, 트리거 발사, 연출 테스트, 세이브, 로그).
편집기에서 Ctrl+S는 바뀐 파일을 모두 저장하고 게임이 다시 컴파일한다(진행 상태는 그대로). 대사 줄을 Ctrl+클릭하면 그녀가 그 줄을 말한다.
`여기서 재생`은 커서가 있는 노트부터 재생하는데, 저장하지 않은 글도 그대로 게임에 보낸다. `#input` 질문은 실행 탭의 대답 칸으로도 답할 수 있다.
셸에서는 `python engine/bridge/cli.py story.state` 같은 `story.*` 명령과 `node scripts/story-check.mjs`(컴파일 + 검사 + 퍼즈)를 쓴다.
